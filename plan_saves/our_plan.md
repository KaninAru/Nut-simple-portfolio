# Portfolio Website Project Plan

This roadmap covers the lifecycle of building and deploying your Data Analyst portfolio.

#### Phase 1: Setup & Environment
1.  **Repository Initialization:** Create a new repository on GitHub named `portfolio` (or your preferred name).
2.  **Local Workspace:** Clone the empty repository to your local machine.
3.  **Tooling:** Ensure you have a standard text editor. No complex frameworks are needed; we will use Vanilla HTML/CSS.

#### Phase 2: Core Development
1.  **Architecture:**
    *   `index.html`: Semantic structure for Hero, Projects, and Contact sections.
    *   `style.css`: Modern dark theme implementation using CSS variables and Flexbox/Grid for layout.
    *   `assets/`: Directory for any icons or images.
2.  **Styling & Design:**
    *   **Typography:** Google Fonts integration for *JetBrains Mono*.
    *   **Theming:** Dark palette definition (`#0f172a` background, `#e2e8f0` text, `#38bdf8` accents).
    *   **Hero Section:** High-contrast display of your name and title.
    *   **Projects Grid:** Three distinct cards containing project titles, descriptions, and links.
    *   **Contact Section:** Direct contact links (e.g., mail, social media).

#### Phase 3: Validation & Refinement
1.  **Responsive Testing:** Verify the layout works on mobile and desktop by resizing your browser.
2.  **Asset Check:** Ensure all links (internal/external) are relative and correctly pointed.
3.  **Code Quality:** Perform a final walkthrough of the CSS for clean selector usage.

#### Phase 4: Deployment
1.  **Commit:** Finalize all local changes (`git add .`, `git commit -m "Complete initial portfolio build"`).
2.  **Push:** Push to the `main` branch on GitHub.
3.  **Activation:** Access the **Settings > Pages** tab on your GitHub repository to enable the deployment.
4.  **Verification:** Visit the provided URL to confirm live status.
